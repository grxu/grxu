# BIIIG concert tee: final pack

A fan-made concert tee in two colourways, black and white. The pack has the
vendor print files, an A3 print spec sheet for each colour and the four
ghost mannequin mockups.

## Folders

| Folder | What's in it |
|---|---|
| `print-files/black-tee/` | Front and back for the black tee, as .ai, .pdf, .svg and a 300 dpi .png |
| `print-files/white-tee/` | The same for the white tee |
| `spec-sheets/` | `spec-sheet_black-tee` and `spec-sheet_white-tee`, A3, as .pdf and .png |
| `threads-mockups/` | The four 1080×1350 mockups: black and white tee, front and back |

## Print spec

| | Black tee | White tee |
|---|---|---|
| **Garment** | Black cotton tee, oversized / drop-shoulder | White cotton tee, oversized / drop-shoulder |
| **Front** | 10 × 3.4 cm, wearer's left chest. Blue, red, yellow | Same |
| **Front placement** | Top edge 18 cm below the centre-front collar seam. Left edge 10 cm from the centre line | Same |
| **Back** | 32 × 38.9 cm, centred. White ink | 32 × 38.9 cm, centred. Blue, red, yellow |
| **Back placement** | Top edge 15 cm below the centre-back collar seam | Same |

- **Inks:** blue `#0756C6`, red `#E73A07`, yellow `#FDBB05` (sRGB), and on
  the black tee's back, 100% white.
- **Print method:** every part is flat spot colour, so it can be screen
  printed. DTF or DTG work too.
- **Background:** transparent everywhere. Print only the artwork, never the
  shirt colour.
- **Sizing:** the same print size on every shirt size, unless the vendor
  advises otherwise.
- **Files:** everything is vector, so there are no fonts or linked images.
  The .ai is a PDF-compatible copy of the .pdf, as in the BIGBANG pack.
  Illustrator opens it directly.

## Before it goes out

- **Back print area:** the back is 32 × 38.9 cm, 2.3 cm taller than the
  BIGBANG back. Check that the vendor's print area fits it.
- **White tee back:** use the white-tee back file. Its three colours butt
  together with no gap. If the vendor screen prints it, ask them to add their
  usual trap where the colours meet.
- **Approval:** get the vendor's file preference, and approve both
  colourways before printing.

## Rights note

The BIIIG artwork is redrawn from an existing poster, so it isn't original
art. It's fine for personal or fan use. Selling the shirts would need
permission from the owners of the artwork and the name.
