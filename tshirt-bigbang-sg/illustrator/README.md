# Illustrator files

| File | Contents |
|---|---|
| `FRONT_left-chest_100x100mm.ai` / `.svg` | 10 × 10 cm artboard. Two placed watercolour images (**iris spray**, **peony + rose**), each movable or scalable on its own, plus the white **B** as a vector path. A clipping path keeps a 1 mm black gap around the B. |
| `BACK_270x317.4mm.ai` / `.svg` | 27 × 31.7 cm. BIGBANG wordmark and the three brushed piano keys, all vector, white ink. |
| `*_check.png` | Quick previews on a black shirt colour. |

- The **.ai** files are PDF-compatible, so Illustrator opens and edits them
  directly. Choose **File → Save As → Adobe Illustrator (.ai)** once to make
  them fully native. In this format everything arrives as groups on one layer.
- The **.svg** files open in Illustrator with the named groups/layers intact:
  *Flowers*, *B (white ink)*, *BIGBANG wordmark*, *Piano keys*.
- Text is already outlined, so no fonts are needed.
- Moving the B: the 1 mm gap is a clipping path on the flowers group. Select it
  in the Layers panel and move it with the B (or release it if you don't want
  the gap).
- Background is transparent. The black shirt is not part of the art.
