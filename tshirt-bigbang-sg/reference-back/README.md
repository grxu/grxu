# Drop the back (piano keys) reference here

Upload the image(s) that show how the piano keys on the back should look.
Higher resolution is better: the original product photo, a close-up, or
several angles all help.

1. On GitHub, open this folder on branch `claude/brave-edison-i18pzh`:
   https://github.com/grxu/grxu/tree/claude/brave-edison-i18pzh/tshirt-bigbang-sg/reference-back
2. Click **Add file → Upload files**, then drag the image(s) in. Any filenames
   and formats (PNG, JPG, WEBP) work.
3. Choose **Commit directly to the `claude/brave-edison-i18pzh` branch**, then
   click **Commit changes**.

These are references only. Nothing in this folder gets printed.
