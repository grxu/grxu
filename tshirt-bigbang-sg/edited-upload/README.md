# Upload your edited artwork here (for the mockup)

Put the front and back here. **Include "front" or "back" in each filename**
(e.g. `front.ai`, `back.png`) so I know which is which. If you only changed
the front, just upload the front.

Any of these formats work:
- **.ai**: keep **"Create PDF Compatible File"** ticked in the Save options (it's
  on by default), otherwise I can't read it.
- **.pdf**: File → Save As → Adobe PDF.
- **.png**: File → Export → Export As → PNG, **transparent background**, 300 ppi.

Keep the artboards at their print size (front 10 × 10 cm, back 27 × 31.7 cm),
so the mockup shows the real size on the shirt.

How to upload:
1. Open https://github.com/grxu/grxu/tree/claude/brave-edison-i18pzh/tshirt-bigbang-sg/edited-upload
2. Click **Add file → Upload files** and drag the files in.
3. Choose **Commit directly to the `claude/brave-edison-i18pzh` branch**, then
   click **Commit changes**.
