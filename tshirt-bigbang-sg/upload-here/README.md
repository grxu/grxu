# Drop the watercolour flowers PNG here

1. Download the full PNG of the chosen option from Higgsfield. Use the
   original file, not a screenshot, so the transparent background survives.
2. On GitHub, open this folder on branch `claude/brave-edison-i18pzh`:
   https://github.com/grxu/grxu/tree/claude/brave-edison-i18pzh/tshirt-bigbang-sg/upload-here
3. Click **Add file → Upload files**, then drag the PNG in. Any filename works.
4. Choose **Commit directly to the `claude/brave-edison-i18pzh` branch**, then
   click **Commit changes**.

`src/build.py` uses the PNG in this folder as the front's flower layer. Keep
only one PNG here.
