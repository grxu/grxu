# Questions for the bag vendor

Send these before the final file. Ask the first two now, because they can change the art.

1. **Print method:** sublimation, DTF, digital or screen print? Is it full colour (photo-like)?
2. **Finest line:** what's the thinnest line that prints cleanly on this fabric? (Matters for the drawing style's fine hatching.)
3. **Lead time:** how many days from final file to finished bags? The party is under 2 weeks away.
4. **Side panels and bottom:** they stay plain. Which fabric colours are available, so we can match the palette?
5. **File:** we'll send a layered PSD on your 2050 × 1656 template with your guide layer kept. Should the guide layer be hidden or visible? Is 200 ppi correct, or do you want 300?
6. **Colour:** should the file be RGB (as the template is) or CMYK? Do you have a colour profile?
7. **Proof:** can you send a photo of one printed sample before the full run?
